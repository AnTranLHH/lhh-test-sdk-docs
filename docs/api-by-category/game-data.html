    Game data & Invoke

    Read and write PlayerPrefs-backed values and invoke component methods on the game player.

    Methods

    • LHH_TestSDK.DeleteAllGameData() — Deletes every PlayerPrefs entry on the game player.
    • LHH_TestSDK.DeleteGameData(string) — Deletes one PlayerPrefs key on the game player.
    • LHH_TestSDK.GetGameData(string) — Reads PlayerPrefs from the game player for the given key (returned as string).
    • LHH_TestSDK.InvokeMethod(string, string, string, params object[]) — Invokes an instance method on a component in the game player and returns the result as a string.
    • LHH_TestSDK.InvokeMethod<T>(string, string, string, params object[]) — Invokes an instance method on a component and deserializes the string result as T.
    • LHH_TestSDK.SetGameData(string, float) — Writes a float PlayerPrefs value on the game player.
    • LHH_TestSDK.SetGameData(string, int) — Writes an int PlayerPrefs value on the game player.
    • LHH_TestSDK.SetGameData(string, string) — Writes a string PlayerPrefs value on the game player.

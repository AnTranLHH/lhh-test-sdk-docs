    Class LHH_TestSDK

    Entry point for automated tests against a device build from the Unity Editor (NUnit, Edit Mode or Play Mode).

    Inheritance
    Object
    LHH_TestSDK
    Namespace: Global
    Assembly: LHH.TestSDK.Docs.dll
    Syntax
    public sealed class LHH_TestSDK : MonoBehaviour
    Remarks

    First API call on a run: connect to Test Controller, lease device, Appium session, wait for player hub. Configure via menu LHH Test SDK - Settings (gRPC, platform, app path, bundle id). Requires LHH_AUTOMATION_TEST and a running Test Controller. Editor-only; not in player builds.

    ConnectTestDeviceAsync()

    Leases a device, starts or reuses an Appium session, and waits for the in-app command hub—without running tests.

    Declaration
    public static Task ConnectTestDeviceAsync()
    Returns
    Type Description
    Task
    Remarks

    Use from the Test SDK settings window while authoring tests so the first SDK call in a test does not pay full setup cost. After a script change, Unity reloads the domain and clears local SDK state; the controller may still hold the lease and device app. Call this again (or rely on implicit setup on the next SDK call) to re-open the gRPC client and re-sync; existing lease/Appium/hub are reused when possible.

    TapObject(string, float)

    Waits for an object, reads its Unity screen position, and taps that point through Appium.

    Declaration
    public static Task TapObject(string objectPath, float timeoutSeconds = 30)
    Parameters
    Type Name Description
    string objectPath

    Hierarchy path with / separators (same rules as WaitForObject).
    float timeoutSeconds

    Maximum seconds to wait for the object before failing.
    Returns
    Type Description
    Task
    Remarks

    Runs implicit setup on first use. Polls every 2 seconds. The player returns Camera.main.WorldToScreenPoint of the renderer bounds center, then collider bounds, then transform.position. A RectTransform uses the screen point of its rect center. The result also includes Screen.width and Screen.height. Unity screen coordinates (origin bottom-left) are flipped on Y and scaled to the Appium window, then tapped.

    Examples
    await LHH_TestSDK.TapObject("HUD/PlayButton");
    Exceptions
    Type Condition
    InvalidOperationException

    Setup failed, the screen position could not be read, or the tap was rejected.
    TimeoutException

    Object not found before timeoutSeconds elapses.

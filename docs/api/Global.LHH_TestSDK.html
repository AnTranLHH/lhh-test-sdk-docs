    Class LHH_TestSDK

    Entry point for automated tests against a device build from the Unity Editor (NUnit, Edit Mode or Play Mode).

    Inheritance
    System.Object
    LHH_TestSDK
    Namespace: Global
    Assembly: LHH.TestSDK.Docs.dll
    Syntax
    public sealed class LHH_TestSDK : MonoBehaviour
    Remarks

    First API call on a run: connect to Test Controller, lease device, Appium session, wait for player hub. Configure via menu LHH Test SDK - Settings (gRPC, platform, app path, bundle id). Requires LHH_AUTOMATION_TEST and a running Test Controller. Editor-only; not in player builds.

    Remarks

    Called automatically when the Unity Test Runner finishes a run or reports a runner error. Manual calls are rarely needed; use only if you run tests outside the Test Runner or need early teardown.

    ClickButton(string, float)

    Waits for a UI object, then invokes its Unity UI Button onClick in the running game.

    Parameters
    Type Name Description
    string buttonPath

    Hierarchy path with / separators (root via GameObject.Find, children via Transform.Find).
    float timeoutSeconds

    Maximum seconds to wait for the button object before failing.
    Returns
    Type Description
    Task
    Remarks

    Runs implicit setup on first use, then WaitForObject(buttonPath) before click. Not for native store UI; use PurchaseByButton for IAP buy buttons.

    Examples
    await LHH_TestSDK.ClickButton(
    "PopupManager/ShopConfirmPopup(Clone)/Panel/Background/Button Confirm");
    Exceptions
    Type Condition
    InvalidOperationException

    Setup failed, hub command failed, or click could not run.
    TimeoutException

    Object not found before timeoutSeconds elapses.

    PurchaseByButton(string)

    Clicks an in-game shop buy button and completes purchase via the native store UI.

    Declaration
    public static Task<bool> PurchaseByButton(string buttonPath)
    Parameters
    Type Name Description
    string buttonPath

    Hierarchy path to a Unity UI Button (same format as WaitForObject).
    Returns
    Type Description
    Task<bool>

    True if the Test Controller reports success; false otherwise.
    Remarks

    Controller taps the button, waits for the IAP sheet, and confirms buy. Use ClickButton for non-IAP UI. Use Purchase when you have a catalog product id instead of a button path.

    Examples
    bool ok = await LHH_TestSDK.PurchaseByButton(
    "__VIEWS__/Shop/.../Button Buy");
Assert.IsTrue(ok);
    Exceptions
    Type Condition
    InvalidOperationException

    Setup failed, or the purchase client is not initialized.

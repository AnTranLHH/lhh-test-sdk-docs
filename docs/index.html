    LHH Test SDK

    Use LHH_TestSDK from NUnit tests in the Unity Editor to drive a real Android device build through the Test Controller: game UI, waits, PlayerPrefs checks, and in-app purchases. iOS is not supported yet.

    Section Purpose
    Manual Install SDK, controller, write and run tests (for QA)
    Scripting API Generated reference for LHH_TestSDK from XML doc comments in code

    Before you write tests

    1. Add com.lhh.testsdk from Bitbucket and run Install Test SDK in LHH Test SDK → Settings.
    2. Install and Run Test Server from the same window (Advance Settings).
    3. Set gRPC address, Android app path (.apk), and bundle id; use an APK that includes InAppTestRunner.

    Start with the Manual.

    Quick example

    [Test]
public async Task Shop_opens_on_home()
{
    await LHH_TestSDK.WaitForScene("Home", timeoutSeconds: 50f);
    await LHH_TestSDK.WaitForObject("iap_manager");
    await LHH_TestSDK.ClickButton("__VIEWS__/Shop/.../Open Shop");
}

    Requires Unity 2022.3.67f2 or newer.

    LHH Test SDK

    Use LHH_TestSDK from NUnit tests in the Unity Editor to drive a real Android device build through the Test Controller: game UI, waits, PlayerPrefs checks, and in-app purchases. iOS is not supported yet.

    Section Purpose
    Manual Install SDK, controller, write and run tests (for QA)
    Scripting API Generated reference for LHH_TestSDK from XML doc comments in code

    Before you write tests

    1. Add com.lhh.testsdk from Bitbucket and run Install Test SDK (Show Advance Settings).
    2. Install Test Controller (Advance Settings), then Run Test Server under Session & server.
    3. Set App path (required), bundle id, and optional Test device; use an APK with InAppTestRunner. Optionally Connect test device before running tests.

    Start with the Manual.

    Quick example

    [Test]
public async Task Shop_opens_on_home()
{
    await LHH_TestSDK.WaitForScene("Home", timeoutSeconds: 50f);
    await LHH_TestSDK.WaitForObject("iap_manager");
    await LHH_TestSDK.ClickButton("__VIEWS__/Shop/.../Open Shop");
}

    AppsFlyer event checks

    Development builds with LHH_AUTOMATION_TEST and AppsFlyer plugin 6.18.x record every AppsFlyer.sendEvent and logAdRevenue call the game makes. Games need no code change: the SDK hooks in once AppsFlyer finishes init. Calling LHH.TestSDK.Integrations.AppsFlyerHook.AppsFlyerRecorder.Install(); right after AppsFlyer init is optional. Purchase Connector purchases and events sent before the hook installs are not recorded.

    LHH_TestSDK tcli
    WaitForAnalyticsEvent wait-for-analytics-event <name> [--param k=v ...] [--since-seq] [--timeout]
    GetAnalyticsEvents analytics-events [--name] [--since-seq] [--since-time] [--limit]
    ClearAnalyticsEvents analytics-clear
    GetAnalyticsHookStatus analytics-status 
    await LHH_TestSDK.ClearAnalyticsEvents();
// ... play the first level ...
await LHH_TestSDK.WaitForAnalyticsEvent("af_level_achieved",
    new Dictionary<string, string> { ["af_level"] = "2" }, timeoutSeconds: 90f);

    Requires Unity 2022.3.67f2 or newer.

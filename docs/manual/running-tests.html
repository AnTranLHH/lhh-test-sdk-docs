    Running tests

    Android only until a future release documents iOS.

    Checklist before Run

    1. Test SDK installed in the project (Install the Test SDK).
    2. com.lhh.testcontroller.shared present and aligned with the SDK/controller version dev released.
    3. Test Controller Running in LHH Test SDK → Settings → Advance Settings (Run Test Server).
    4. Android device connected (USB debugging); controller can see it via Appium.
    5. Settings filled in:
      • Platform: Android
      • App path: automation-enabled APK (contains InAppTestRunner + LHH_AUTOMATION_TEST on Android)
      • Bundle ID matches the APK (override or Player Settings)
      • gRPC server address: http://127.0.0.1:5050 unless your machine uses another host/port
    6. Player build is the version QA expects (rebuild and refresh App path after SDK/shared updates).

    Run from Test Runner

    1. Window → General → Test Runner
    2. Select EditMode (or PlayMode if your team uses it for specific tests).
    3. Run one test, a fixture, or all tests.

    On the first LHH_TestSDK call in that run, the SDK performs implicit setup (device lease, Appium session, hub wait). Setup can take tens of seconds—this is normal.

    When the entire run completes (pass or fail), the SDK returns the leased device automatically. You rarely need to call CleanUpAfterTest yourself.

    What “good” looks like

    • Unity Console: setup logs, then your test logs/assertions.
    • Device: app launches (if App path set), UI responds to clicks driven from the Editor.
    • No InvalidOperationException for hub not connected or device assignment failed.

    Troubleshooting

    Symptom Things to check
    Command hub is not connected APK built without InAppTestRunner / automation define; wrong bundle id; controller not running; firewall blocking gRPC.
    Test device assignment failed Another test holding the device; controller not running; no free Android device.
    Timed out waiting for object/scene Wrong path (use Extract Object Path); object not loaded yet—increase timeout; game not on expected scene.
    Failed to click button Path not a Button; object inactive; use WaitForObject path first.
    Purchase failures Use PurchaseByButton / Purchase; store/account sandbox; allow up to 3 minutes for Purchase.
    Empty app path warning Set App path in Settings; session may not launch the build you intend.
    RPC / type errors after upgrade Update com.lhh.testsdk and com.lhh.testcontroller.shared, re-run Install Test SDK, restart Test Server, use a new APK.

    For controller-side logs, see the Progress panel in Settings or logs under ~/lhh-auto-test-controller/.run/ when using the installed controller repo.
